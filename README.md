# Упражнения с файлами

main сейчас пустой. В комментариях находятся примеры чтения строк, нумерации и копирования файлов, работы с flag и os. data.txt — пример данных, numberedData.txt — сохранённый результат нумерации.

Учебная папка `basics/files`. Код сохранён в исходном состоянии.

## Структура

- `.gitignore`
- `data.txt`
- `go.mod`
- `main.go`

## Требования и команды

Проверено на Windows с Go 1.27.1 (windows/amd64); `go.mod` требует Go 1.27.1. Команды выполняются из корня репозитория.

Точка входа: `main.go`.

```sh
go run .
```

```sh
go test ./...
go vet ./...
```

## Результаты проверки

- `go test ./...`: успешно (код 0).
- `go vet ./...`: успешно (код 0).
- `go run .`: успешно (код 0).

Файлов `*_test.go` нет. Успех `go test` здесь означает проверку сборки, а не прохождение набора тестов.
